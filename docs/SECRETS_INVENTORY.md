# Horae — Secrets & Config Inventory

**Names only — never put real values in this file.** This is the checklist of every
secret/config value the app needs, so you can (a) store the real values in a password
manager, and (b) re-enter them if you ever rebuild the Supabase or Vercel project.

Generated by scanning the codebase on 2026-08-31. Re-scan when functions change:
`grep -rhoE 'Deno\.env\.get\("[A-Z0-9_]+"\)' supabase/functions`.

Project ref: `vexqmdrldxhwrpcwbxow`

---

## 1. Supabase project-level (Dashboard → Project Settings)
Record these — losing them means clients/data can't be reached or restored:

| Value | Where to find it | Notes |
|---|---|---|
| **DB password** | Settings → Database | Needed for backups (`SUPABASE_DB_URL`) and restores. |
| **Connection string (URI)** | Settings → Database → Connection string | Used by `scripts/backup-db.ps1`. |
| **`anon` key** | Settings → API | Public; used by the frontend. |
| **`service_role` key** | Settings → API | **SECRET.** Auto-injected into edge functions; record it for rebuilds. |
| **Project URL** | Settings → API | e.g. `https://vexqmdrldxhwrpcwbxow.supabase.co` |
| **JWT secret** | Settings → API | Record if you ever migrate auth. |

> `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` are **auto-injected** into edge
> functions by Supabase — you don't `secrets set` them, but you still want them
> recorded above for a from-scratch rebuild.

## 3. Supabase Edge-Function secrets (`supabase secrets set NAME=value`)
Set via Dashboard → Edge Functions → Secrets, or CLI. Split into true secrets vs plain config.

## 4. External accounts to keep credentials for (not env vars, but part of a rebuild)
- **Meta / WhatsApp**: Meta Business account, WABA id, phone number, the approved message templates, and the webhook callback URL + verify token registration.
- **Vercel**: the project + its domain and env vars.
- **Supabase**: the project itself + its backups/PITR settings.
- **GitHub**: `CodeRookie84/horae-cloud` (enable 2FA + branch protection on `main`).
- **LLM providers**: Groq, Google AI Studio (Gemini), Anthropic — the API keys above.
